# Готовность локального демо и отдельная проба света

28 октября 2026. Базовая сохранённая версия — c5b1444, исходники до доработки: work/snapshots/before-motion-plus-c5b1444.zip. Сервер 4173 продолжает обслуживать dist текущего проекта. Публичный Pages не обновлялся, видео не записывалось.

## Основная страница

Сохранены компактные интервалы, четыре направления с графикой, четыре честно подписанных временных AI-портрета, серебряная семейная эмблема и все прежние пользовательские правки. Добавлены короткая побуквенная сборка заголовка, однократная прорисовка контуров услуг, раздвижное раскрытие портретов и локальная линия чтения принципов. Новых секций, пустого scroll travel и pin нет. Основной текст остаётся непрозрачным, быстрый/обратный скролл сразу завершает входящие эффекты.

Выбранный портрет переходит в нативный диалог через View Transitions там, где API доступен и движение разрешено. В переходе используется одно изображение, без двоения лиц; текст карточки показывается после остановки фотографии. Пока текст ещё не видим, его элементы исключены из фокуса. Escape/возврат фокуса и ловушка Tab сохранены. Без API используется короткое обычное открытие; reduced motion открывает статично. Без JavaScript коллекция остаётся сеткой.

## Отдельная световая проба

Основная версия: http://localhost:4173/?review=motion-ready#top

Проба: http://localhost:4173/?scene=sculpture&review=motion-ready#top

Проба не заменяет основной экран. В ней текст и CTA видны сразу; под знаком есть повтор и переход к обычной версии. За 3.4 секунды виртуальный свет раскрывает рельеф, затем движение останавливается. Указатель мягко меняет вид и отражения; на телефоне hover не требуется. Сцена уходит с hero и останавливается вне экрана/скрытого документа. При reduced motion, недоступном WebGL2 или потере контекста остаётся исходный статичный SVG.

Реализация: нативный WebGL2, ray marching неглубокого скруглённого объёма по distance field исходного семейного силуэта. Это процедурный объёмный рельеф, не CSS-наклон картинки и не авторская CAD-модель. Исходные векторные контуры не перерисованы. Поле 2048px, 289KB; модуль около 7.2KB. Оба загружаются только по URL пробы. Зависимости и платные API не добавлялись. Техническое происхождение и восстановление: public/brand/SILVER-STUDY.md.

Прототип сначала был слишком плоским; рельеф, контраст отражений и нормали уточнены по последовательным кадрам. Остаточная неровность трассированного контура сохраняется. Проба подготовлена для визуальной оценки, а не объявлена окончательным премиальным мастер-логотипом. Основной проверенный серебряный SVG остаётся вариантом по умолчанию для демонстрации заказчику. Для идеально чистой кромки нужен оригинальный векторный мастер клиники.
