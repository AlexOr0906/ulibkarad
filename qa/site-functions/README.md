## Получение и воспроизведение

```sh
git fetch origin feature/site-functions qa/site-functions
git show origin/qa/site-functions:qa/site-functions/README.md
git show origin/qa/site-functions:qa/site-functions/results.json
```

В собственной копии кода: npm ci, npm run build, static preview dist, затем `node scripts/verify-site-functions.mjs`. PREVIEW_URL и BROWSER_PATH можно переопределить. Проверенный локальный адрес — http://localhost:4186/; на другом компьютере сервер нужно запустить самостоятельно. Кадры/диагностика остаются в игнорируемом work/verification/site-functions.

Описание архитектуры и полей — SITE-FUNCTIONS.md в feature-ветке. Режим не является заявлением о соответствии стандартам. Проверен настольный Chrome с мобильной эмуляцией; физические устройства и Safari не проверены. Нет настоящей записи, анкетирования, аналитики, backend или CMS. Список юридически обязательных сведений требует отдельной сверки по отсутствующему REQUIREMENTS-PLAN.md. Поиск не анализирует PDF и не выполняет морфологический анализ.

Main и Pages не обновлялись. Отчёт нельзя автоматически считать проверкой изменений после указанного SHA.
