# Graphic portrait studies

Four native SVG faceless studies for the explicitly labelled demo collection. They are anonymous graphic layouts, not photographs or fictional clinic employees. No faces, names or credentials have been invented or copied from InSmile. Reproduce with scripts/build-portrait-studies.py.

The reference informs unified background/crop, portrait emphasis and collection controls. Actual portrait impact still requires agreed photographs of the clinic's real staff. Replace studies through src/data/doctors.ts, with confirmed name, specialty, short information and an optional real profile address.
