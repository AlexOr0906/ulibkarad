# About: план до реализации

29.10.2026. Ограниченная внутренняя страница, не новый сайт и не переделка согласованной главной. База87d3e55, контракт обмена отдельным коммитомb5ae25c. Общий layout/переходы принадлежат второму аккаунту.

## Направление

Холодная бумага #EEF1F3, поверхность #F5F6F6, графит #273037, светлый текст #F2F4F5, серебро #C9CDD1, вторичный #596770. Существующий Manrope для кириллицы; Cormorant только в латинском OrthoFamily. Протяжённый заголовок слева, крупное честное место для реального фото справа. Не имитировать интерьер клиники и не добавлять вымышленные достижения.

```
breadcrumb
hero: большой текст + действия | место реального фото
graphite: подход, крупная фраза | короткий рассказ
paper: компактные сведения, доступные для проверки
close: знакомство с командой + контакт
```

На телефоне один естественный поток: текст/ранние ссылки, затем медиа, рассказ и сведения. Нет pin, длинной пустой сцены или графики по тексту. Ширина/поля совместимы с текущей главной.

## Путь и движение

1. Знакомство: цель страницы ясна по хлебным крошкам и заголовку; бренд и семейная подпись сохранены. Заголовок раскрывается последовательно, текст чуть позже.
2. Атмосфера: умеренное раскрытие крупного медиа. Пока фото нет, спокойная серебристая поверхность с подлинным знаком и явной подписью; это не фотография клиники.
3. Смысл: смена бумаги на графит даёт эмоциональный акцент, короткий рассказ в своей колонке. Без неподтверждённых гарантий/оснащения/стажа.
4. Уверенность и действие: компактные известные сведения и прямые ссылки к реальным разделам врачей/контактов на главной. Материалы остаются демонстрационными до утверждения.

Локальный однократный reveal для групп текста/медиа, мягкое движение16–20px, обычный нативный scroll. Не повторять длинный hero главной. Никакого router/page-transition кода; экспортируемый идемпотентный initializer с cleanup. Reduced/no-JS сразу читаемы, быстрый hash/scroll/focus завершают нужные эффекты.

Проверить реальные пиксели на1440/768/390/320px, keyboard, hash, back/forward, быстрый/обратный scroll, no-JS/reduced; ссылка к врачам/контакту работает с BASE_URL. Главное отличие от generic-шаблона — типографическая открытая композиция и один графитовый смысловой поворот, а не набор одинаковых карточек или выдуманных числовых преимуществ.
