# Два варианта для выбора заказчиком

28 октября 2026. Владелец попросил подготовить оба варианта для одновременной отправки заказчику. Публикация необходимых страниц на существующем GitHub Pages входит в этот запрос. Сообщение заказчику автоматически не отправляется.

## Адреса

- `/compare/` — краткое объяснение, реальные превью и открытие вариантов в отдельных вкладках.
- `/variant-a/` — первая опубликованная композиция: фиксированная горизонтальная лента на фоне разделов, без первого экрана и футера.
- `/variant-b/` — эксперимент с пятью лентами в существующих отступах разделов.
- Корневой адрес сохраняет первый вариант, поэтому прежняя ссылка остаётся пригодной.

Для GitHub Pages перед путями используется `/ulibkarad/`. Активный вариант выбирается при статической сборке, через props общего `DemoPage.astro`. У первого в HTML только BracketBackground, у второго — только пять BracketDivider. Нет определения варианта по query-параметрам и скрытого параллельного слоя. Содержание и общая длина страницы одинаковы.

Все меню, фрагментные ссылки, демоформа, диалог и шрифты используют общую реализацию. Материалы, фотографии декорации и превью используют BASE_URL. Превью сняты с окончательной композиции двух вариантов в одинаковой позиции страницы и одинаковом размере 1440×900. Формы остаются локальными и ничего не отправляют.
