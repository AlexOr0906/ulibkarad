# Три кадра для каждой страницы терапии

31.10.2026. Локальный вариант в `codex/therapy-signature-scenes`. Предыдущие прототипы сохранены по адресам `*-therapy-scene-preview/`; основные страницы не заменены.

## Просмотр

- http://localhost:4207/children-therapy-story-preview/
- http://localhost:4207/adult-therapy-story-preview/

Node 24, существующий lockfile. `npm ci` в новой копии, `npm run build`, затем `python -m http.server 4207 --bind 127.0.0.1 --directory dist` (только на свободном порту). Localhost доступен на этом компьютере, не внешняя ссылка для заказчика.

## Сценарии

Детская: знакомство с врачом → разговор ребёнка, родителя и врача → объяснение на модели. Три разных момента одного вымышленного знакомства. Переходы с коротким боковым перемещением и смешением кадров, без деформации лиц.

Взрослая: крупный план инструмента и рук → врач за работой у столика → весь кабинет. Смена крупности через масштаб и мягкое смешение кадров. Это постановочная визуальная история, не демонстрация клинической процедуры. Генерированные ракурсы не являются геометрически точным непрерывным отъездом камеры; реальная согласованная съёмка улучшит совпадение рук и положения предметов.

Прокрутка нативная. Стопы до первой смены, между кадрами и после второй; переходы на 16–40% и 56–80% участка. Никакого wheel/touch interception, непрерывного RAF, видео и новых зависимостей. На телефоне более короткий участок и своя высота кадра; при reduced motion, чтении, no-JS или низком горизонтальном экране все три кадра идут обычной лентой. Ошибка decode оставляет статичный сценарий.

Локальный lifecycle: WeakMap, AbortController, cleanup на pagehide без bfcache; pageshow пересчитывает геометрию. Общий router/header/layout не изменены. В wrapper добавлен только необязательный storyboard-параметр, старые маршруты сохраняют прежний вариант.

## Материалы и замена

`children-source.png`, `adult-source.png` созданы штатным ImageGen 31.10.2026. Все люди и помещения вымышлены; AI-подпись есть на обеих страницах. Третьесторонние фото не использованы. Каждый исходник — лист из трёх связанных кадров; CSS выбирает нужную область листа. При оптимизации выполнялось только WebP-кодирование существующим sharp.

Runtime: `public/therapy-storyboards/children.webp` 160952 байта; `adult.webp` 136950 байт. В репозитории также сохранены исходные PNG. Нет зависимости от локальных generated_images-путей.

Для реальной детской страницы нужны: портрет врача на уровне ребёнка; знакомство с ребёнком и родителем; объяснение на модели — один свет, одежда и помещение. Для взрослой: руки/инструмент крупно; тот же врач и действие средним планом; общий кабинет. Лучше снять серию в одну сессию. Для смартфона важные лица/предметы должны оставаться в центральной области. Публикация изображений людей должна быть согласована клиникой. Медицинские утверждения не добавлялись.
