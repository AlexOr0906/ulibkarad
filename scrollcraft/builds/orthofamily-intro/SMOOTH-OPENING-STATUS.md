# Плавный переход вступления

Ветка: `feature/opening-transition`. Основа сравнения: `07f6a2433f3e423383580983cd1366f7b5ec1909` из `feature/orthofamily-home`.

Новая задача пользователя заменяет прежнее требование почти неподвижного зеркала: сделать выразительнее движение предмета и переход светлого фона в графитовый. Остальные блоки сохраняются.

## Композиция

В браузере просмотрен Inwhite Medical: предмет, светлая овальная форма и текст перемещаются независимо; при прокрутке появляется тёмный фон. Заимствован принцип независимых планов, без переноса изображений, текстов и кода референса.

В OrtoFamily используются существующий прозрачный WebP зеркала и три локальных плана: отступающая светлая поверхность с округлым краем, отдельная серебристая овальная подложка, зеркало с поворотом, небольшим масштабированием и бликом по его альфа-маске. Это CSS-композиция, не 3D-модель. Прежний радиальный фон переопределён только внутри `.of-opening-transition`.

Прокрутка нативная. Единственный requestAnimationFrame обновляет свойства сцены; короткое экспоненциальное сглаживание заменяет CSS transition на каждом кадре. Большой скачок сразу синхронизирует сцену. Текст и кнопки не скрываются анимацией. На телефоне меньше перемещение и поворот; существующая мобильная компоновка сохранена. При reduced-motion геометрия статична, блик отключён; без JS содержимое доступно.

## Подключение

`OrthofamilyIntro.astro` импортирует новый `opening-transition.css`, задаёт класс и URL маски. `OrthofamilyMotion.astro` меняет только расчёт сцены. Код направлений и диалога не изменён. Новый стиль не подключать глобально отдельно: импорт уже находится в компоненте. Изменения видны в существующих `/orthofamily-preview/` и `/orthofamily-combined/`; корневая страница не переделана.

Эмблема, шапка, врачи, контакты, футер, общие стили, зависимости и lock-файл не изменялись. Устанавливались только уже зафиксированные зависимости через npm ci. Навыки frontend-design и Scroll Craft использованы из проекта; диагностические ограничения прежние: ffmpeg и платный ключ генерации отсутствуют, для CSS-сцены не нужны. Системные программы не устанавливались.

## Проверка

Локальный предпросмотр: `http://localhost:4200/orthofamily-combined/` (доступен на этой машине при запущенном сервере).

`node scripts/verify-opening-transition.mjs` использует playwright-core и установленный Chrome. URL можно переопределить `OPENING_PREVIEW_URL`, путь Chrome — `SCROLLCRAFT_CHROME`. Артефакты сохраняются в `outputs/opening-transition/` и не входят в Git.

Проверяются семь состояний перехода при 1440×1000, 768×1024, 390×844, 320×568 и 844×390; дополнительно desktop/mobile reduced-motion и mobile без JS. Проверяются отсутствие горизонтального переполнения, contain для зеркала, завершение движения, быстрые и обратные скачки, CTA/Escape/возврат фокуса, открытие профиля и листание команды. Снимки начала, середины и конца просмотрены визуально на компьютере и телефоне. Это эмуляция Chrome, не проверка физического телефона или Safari.
