Существующие Header, hero, услуги, врачи, контакты, Footer, корневая страница, BaseLayout, глобальные стили и зависимости не изменены. Новую шапку подключает основной разработчик. Назначение этой новой работы явно задано пользователем после исходного распределения зон в AGENTS.md.

## Дизайн

Сохранены Manrope, прежняя семейная серебряная эмблема (`public/brand/logo-chrome.svg`, без перерисовки) и название «Ортофэмили». Использован существующий ArrowIcon. Палитра: белый #FFFFFF, графит #292D30, вторичный серый #5B5F62, серебро #C9CDD1, светлая поверхность #EBE9EB. Небольшая шапка с ясной иерархией: бренд -> направления навигации -> контрастное действие. Это функциональное продолжение общей основы, а не новая визуальная композиция hero.

На 1100 px и выше — открытая навигация. Ниже — нативный details с большим списком ссылок. На 320/390 эмблема и название сохранены, компактная кнопка «Связаться» остаётся видимой рядом с меню. Полное доступное имя кнопки всегда «Обсудить визит: перейти к контактам».

Темы light/dark задают локальные непрозрачные поверхности и контрастный текст/CTA, поэтому шапка не зависит от фотографии/цвета под ней. Не используется автоматическое угадывание фона, телефоны и внешние шрифты не добавляются.

По умолчанию шапка находится в нормальном потоке страницы, не fixed/sticky. Раскрытие также в потоке и сдвигает содержимое, не накладывается на него; длинный список прокручивается внутри ограниченной панели. Шапка не требует пустого отступа сверху и не перекрывает якоря. Если в будущей интеграции понадобится fixed/sticky-версия, её геометрию и отступы необходимо согласовать отдельно; локальный компонент не меняет общую композицию ради этого.

Открытие 230 мс, закрытие 160 мс: только opacity/transform, без тяжёлой сцены, изменения движка Scroll Craft или scroll-jacking. Не анимируются текст и эмблема при каждой прокрутке. При reduced motion анимации и переходы отключены.

## Интеграция

Перенести коммит задачи на ветку с общей основой и добавить компонент перед основным содержимым вместо прежней шапки. Основная страница в этой ветке не редактировалась.

```astro
---
import ClinicHeader from '@/components/header-navigation/ClinicHeader.astro';
---
<div id="top">
  <ClinicHeader theme="light" />
  <main>...</main>
</div>
```

Для графитового варианта: `theme="dark"`. Компонент сам импортирует `src/styles/header-navigation.css`, правила ограничены префиксом hn-. Общие CSS менять не нужно.

Параметры:

- `theme?: 'light' | 'dark'` (light по умолчанию).
- `links?: HeaderLink[]`: массив `{ label, href }`, по умолчанию из `src/data/header-navigation.ts`.
- `homeHref?: string` (#top).
- `contactHref?: string` (#contacts).
- `instanceId?: string` (orthofamily-header). Если на одной странице несколько шапок, передать разные значения для уникального aria-controls/id панели.

Название шапки и адрес эмблемы учитывают Astro BASE_URL. Данные навигации не меняют общий `src/data/site.ts`.

## Клавиатура и состояние

Нативная summary сохраняет Enter/Space. JavaScript добавляет aria-expanded, короткое открытие/закрытие и Escape с возвратом фокуса на переключатель. В открытой панели Tab идёт по обычным ссылкам; это немодальная навигация, поэтому ловушки фокуса и блокировки body нет. Выход фокуса за пределы раскрытия, нажатие снаружи и выбор ссылки закрывают меню. При выборе локального якоря после закрытия фокус переносится в целевой блок, затем выполняется обычная прокрутка; временный tabindex снимается при уходе фокуса.

Смена ширины на desktop закрывает мобильное меню. Фокус на исчезающей summary/ссылке переносится на видимую кнопку связи. Быстрые повторные нажатия отменяют предыдущее движение без зависшего состояния.

Без JS нативное details открывается/закрывается Enter/Space, ссылки работают; автоматическое закрытие и Escape требуют JS. На странице предпросмотра неработающие переключатели темы скрыты без JS. Никаких телефонных заглушек tel: и фиктивной формы записи нет.

## Уточнение бренда после выбора заказчика

Название в шапке, раскрытом меню, доступном имени и заголовке предпросмотра обновлено на **OrtoFamily**, строго с заглавными O и F. Под названием полная подпись **Стоматология · Ортодонтия**, в том числе на 320px. Прежняя семейная эмблема и палитра сохранены. Красного подчёркивания нет: это отметка выбора, не элемент логотипа.

Для наборного названия используется системный serif Georgia (fallback Times New Roman); подпись, навигация и CTA сохраняют Manrope. Сам брендборд/файл выбранной гарнитуры в этой рабочей копии не предоставлены, поэтому Georgia является временной типографической реализацией направления, а не заявленным точным шрифтом брендборда. После предоставления лицензированного файла основному разработчику достаточно заменить font-family локального wordmark. Новые зависимости и внешние шрифтовые запросы не добавляются.

Это прямое уточнение заказчика новее кириллического написания в общем BRIEF.md. Шапка следует уточнению; общие документы, hero, футер и другие самостоятельные ветки этой задачей не переименовывались. Основному разработчику нужно перенести новое написание при общей бренд-интеграции.
