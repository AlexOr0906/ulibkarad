## Подключение

`src/pages/orthopedics.astro` использует существующий `InternalPageLayout` и `ServicePageContent`. Общий шаблон даёт единственный h1/hero/breadcrumbs. В named slot `scene` передан `OrthopedicsVisual` внутри одного `.or-shell`; default slot полностью заменяет стандартное тело на `OrthopedicsPageContent`. Временный `OrthopedicsPreviewIntro` не подключён. Один header/footer/main, стандартные контентные блоки шаблона не дублируются.

Оба компонента получают `autoMotion=false`. Существующий `internal-lifecycle.ts` вызывает их initializer только для roots без autoMotion, хранит cleanup в существующем массиве disposers. При pagehide без bfcache снимаются обработчики/observer; сохранённый документ bfcache не инициализируется повторно. Нового router или глобального motion-модуля нет. Геометрия сцены/контент/локальные стили при интеграции не переделывались.

Переход с главной: раскрыть «Ортопедия» в «Направлениях», ссылка «О направлении». Добавлен необязательный prop `orthopedicsHref` компонента направлений, передаваемый HomePage. В остальных направлениях поведение прежнее. Шапка/композиция/анимации главной не менялись. Путь услуги строится из BASE_URL; добавлен к списку допустимых переходов без новой позиции в шапке.
