# Элайнер и адаптация телефона, 29 октября 2026

## Основа и решение

Получена итоговая интеграция другого агента: GitHub main `1a8a02d` (включает layered opening `b399ebd` и закрытые по умолчанию направления `0e20723`). Собственная `feature/orthofamily-home` обновлена через fast-forward, чужая папка/ветка не переключались. Публикационный workflow не менялся, нового push main/Pages нет.

Клиент одобрил анимацию и общую подачу, попросил заменить зеркало. Выбрано авторское предложение: отдельный прозрачный ортодонтический элайнер. Это иллюстративная графика, не изображение оборудования клиники и не утверждение клиентом конкретного предмета. Серебристая пластика соответствует существующей палитре. Грамматика/маршрут/фирменный знак/копирайт не перепроектировались; подпись демоматериала остаётся видимой.

## Изменения

- Один оригинальный альфа-ассет. На ПК остаются одобренное движение подложки, независимая серебристая форма за предметом, небольшой ход/поворот и скользящий блик. Визуальная рамка теперь соответствует широкому элайнеру:4:3, с вертикальным центрированием. Это убрало пересечение рамки с текстом на768px.
- На телефоне отдельная геометрия под CTA и уменьшенная амплитуда: масштаб до1.018, вертикальный ход6px, поворот от−2° до2°, без бокового сдвига предмета/подложки. Длительность берётся из стабильной svh-композиции, а не текущего `innerHeight`; resize больше не сбрасывает сглаженный прогресс. Физическое поведение адресной строки iOS пока не проверено.
- Стрелки и закрытие демо-окна в собственных компонентах вступления/направлений/оболочки используют SVG `OrthofamilyIcon.astro`. Шапка, команда и футер уже используют SVG-стрелки; их исходники не менялись.
- Обычный wheel/touch не перехватывается. Reduced motion/no-JS сохраняют доступную статичную страницу; долгого пустого pin нет. Формы остаются демо.

## Ассет и происхождение

Штатный built-in ImageGen, без внешнего платного API. Полный финальный prompt/режим: `design/orthofamily/aligner-object-prompt.json`. Оригинал: `design/orthofamily/aligner-object-v1-source.png`,1448×1086 RGBA. Доставка: `public/orthofamily/aligner-object-v1-640.webp` (59554B) и `public/orthofamily/aligner-object-v1-1200.webp` (175664B). Сохранена настоящая альфа; производные только уменьшены/закодированы. Композит просмотрен на графите; актуальный предмет просмотрен на светлой/тёмной сцене.
